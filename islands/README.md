# 海岛手记 · LW & 5

从主页的贝壳进入，在 LW5 内记录旅行、酒店、八维评分与备注。手记使用浏览器原有的 `lw5-island-journal` IndexedDB；本次更新不新增账号或云同步，不把旅行记录上传到代码仓库。

编辑时先保留为草稿，按「确认保存」才写入。首次成功保存会在同一数据库事务内备份原始状态；返回、取消和切换旅行前会询问未保存的修改。`null` 表示未评分，数字 `0` 是明确零分。旧备份可导入，新备份为兼容零分的 v2 格式。请在换设备或清理浏览器前自行导出备份。

页面「备份与整理 → 关于」提供模型作者、来源、许可和展示改动说明；仓库中的 [完整署名](legal/ATTRIBUTION.md) 及许可证也随项目保留。第三方模型适用各自许可，不以应用代码的许可替代。原模型文件及元数据保留。

部署版本：v58。主页面一键更新只刷新应用缓存，不清理 IndexedDB 或 localStorage。大型模型按需载入，不加入首次安装的核心预缓存。
